# Catálogo digital · Tecno Log IA

App web (GitHub Pages) del catálogo multimarca **solo para distribuidores y mayoristas**.

- `index.html`, `styles.css`, `app.js`: la app (sin instalación, funciona en celular, tablet y PC).
- `config.js`: URL de la API (Google Apps Script). Vacía = usa `data/productos.json`.
- `backend/API_Catalogo.gs`: API en Apps Script (cuenta tecnologiapperu@gmail.com): productos, RUC y órdenes de compra con firma, PDF y correo.
- Datos: hoja «Tecno Log IA · Catálogo App (base maestra)» en Google Drive. Precios, ofertas y estados se editan ahí.
- `assets/p/`: fotos propias de productos (Oster).

Enlaces con origen: `?d=fb`, `?d=yt`, `?d=qr`, `?d=wa`. Producto directo: `?p=<ID>`.
